Admin panel

Database

Backup your data or open the folder where the database is stored.

Meets

Add, edit, duplicate, or remove meets.

Teams

Add or remove teams. Bulk reassign or delete all swimmers in a team.

    Team coaches

    Assign coaches to each team. Coaches who have opened the app appear in the list.

    Invite coaches & admins

    Generate a one-time code for a coach or admin. Send them the code; they enter it when creating an account.

    Users

    View all user accounts (admins, coaches, swimmers). Link swimmer accounts to a profile or get invite codes from the list.

    Relay types

    Availability options shown when adding/editing swimmers (e.g. freestyle, medley).

    Danger zone

    Reset deletes all swimmers and meets. Optionally clear teams too. This cannot be undone.
